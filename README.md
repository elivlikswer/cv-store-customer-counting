# Система подсчёта посетителей на базе компьютерного зрения

Учебный проект по разработке MVP для автоматического подсчёта входящего потока посетителей торговой точки с функциями классификации загруженности и прогнозирования трафика.

## Структура проекта
- `data/` — датасеты и разметка
- `notebooks/` — исследовательские ноутбуки
- `src/` — основной код (детекция, трекинг, аналитика)
- `docs/` — отчёты и документация
